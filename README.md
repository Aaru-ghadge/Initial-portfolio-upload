# Portfolio Website

This is my personal portfolio website built using React and Vite.

## Features
- Responsive design
- Projects section
- About me section
- Contact section
- Modern UI

## Technologies Used
- React
- Vite
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository
2. Open terminal in the project folder
3. Install dependencies

```bash
npm install
```

4. Run the project

```bash
npm run dev
```

## About npm install

`npm install` installs all required packages and libraries for the project.

It reads the `package.json` file and downloads dependencies like:
- React
- Vite
- Express
- MongoDB packages
- etc.

After installation, the `node_modules` folder is created automatically.

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
